# AIOSS — Descargas

Repositorio de distribución de AIOSS para el equipo. Aquí se publicarán los instaladores y los archivos necesarios para verificar las actualizaciones.

Este repositorio no contiene el código fuente de la aplicación, credenciales ni datos de los espacios de trabajo.

## Estado

Todavía no hay una versión pública disponible en Releases. Las actualizaciones desde la aplicación aún no están habilitadas.

## Instalación y actualizaciones

Cuando se publique una versión para Windows, la descarga será un instalador .exe: no será necesario instalar Node.js ni ejecutar comandos.

La versión de prueba 0.1.0 tiene las actualizaciones desactivadas. Será necesario instalar una versión posterior con el actualizador habilitado una vez; después, la aplicación pedirá confirmación antes de reiniciar para actualizar.

No desactives las protecciones de Windows. Si Windows bloquea una descarga o instalación, consulta con el responsable de la distribución.
